# 사용 가이드

[README로 돌아가기](../README.md)

## 시작하기

프로젝트 폴더에서 `npm start`를 실행한 뒤 [http://localhost:4173](http://localhost:4173)에 접속합니다. 호스팅된 사이트를 이용할 때는 해당 사이트 주소를 엽니다.

화면은 **실험 조건 바꾸기 → 변화 관찰하기 → 관찰 노트 남기기** 순서로 사용합니다. 상단의 세 실험 탭으로 이동하고, `처음으로` 버튼으로 현재 실험의 기본 조건을 복원합니다.

## 이슬 · 안개 · 구름

1. `이슬`, `안개`, `구름` 중 하나를 선택합니다.
2. `처음 공기의 습도`를 설정합니다. 처음 공기 온도는 24℃입니다.
3. 이슬은 잎 표면의 온도, 안개는 지표 근처 공기의 온도, 구름은 공기가 올라간 높이를 조절합니다.
4. `생성 과정 보기`를 눌러 조건의 변화를 천천히 관찰합니다.
5. `다시 따뜻하게 해 보기` 또는 `공기를 다시 내려 보기`로 물방울이 줄어드는 모습을 비교합니다.

| 조절 항목 | 범위 |
| --- | --- |
| 처음 공기의 습도 | 30~95% |
| 이슬·안개의 냉각 대상 온도 | 5~30℃ |
| 구름 실험에서 올라간 높이 | 0~2,500m |

이슬은 잎 표면, 안개는 지표 가까운 공기, 구름은 상승한 공기에서 생깁니다. `물방울 확대 표시`는 안개·구름의 확대된 점을 켜거나 끕니다. 구름의 둥근 선은 공기 덩어리의 범위이며, 점선은 계산한 구름 시작 높이입니다. 9초는 관찰용 재생 시간입니다.

## 고기압과 저기압

1. 왼쪽과 오른쪽 기압을 다르게 설정하고 지표 부근 공기의 이동 방향을 확인합니다.
2. `두 지역의 조건 바꾸기`로 방향이 반대로 바뀌는지 비교합니다.
3. `기압만 같게 해 보기`로 기압 차에 의한 전체 흐름이 멈추는지 확인합니다.
4. `밀도 비교`를 선택하고 `같은 온도 · 기압 비교`, `같은 기압 · 온도 비교`를 번갈아 사용합니다.

기압 범위는 990~1,030hPa, 온도 범위는 0~40℃입니다. `입자 흐름`은 공기 덩어리의 이동을, `밀도 비교`는 같은 크기 공간 안의 상대적인 촘촘함을 보여 줍니다. 노란 입자는 경로를 따라 관찰하는 표식입니다.

`차이 강조`를 끄면 계산한 밀도에 비례하는 점 수를 표시합니다. 켜면 기준 상태에서의 밀도와 운동 빠르기 차이를 6배로 강조합니다. 표시 점 수에는 반올림과 상·하한이 적용됩니다. 밀도 숫자와 운동 배수 숫자는 강조하지 않은 계산값입니다.

## 모래 · 물 · 바람

1. `가열 실험` 또는 `냉각 실험`을 선택합니다.
2. 두 물질에 동일하게 주거나 빼는 열을 20~100J/초로 설정합니다.
3. `실험 시작`을 누르거나 `+30초` 버튼으로 진행합니다.
4. 온도 그래프와 입자 흐름을 비교한 뒤 관찰을 기록합니다.

두 물질의 질량은 각각 1kg입니다. 가열은 20℃, 냉각은 30℃에서 시작하며 최대 실험 시간은 300초입니다. 재생 중 실제 1초는 실험 시간 10초에 해당합니다. 열의 양이나 가열·냉각 모드를 바꾸면 시간은 0초로 돌아갑니다.

가열에서는 모래가 더 따뜻해지고 지표 부근 흐름이 물에서 모래로 향합니다. 냉각에서는 모래가 더 차가워져 반대 방향의 흐름을 보여 줍니다.

## 화면 조작

| 조작 | 동작 |
| --- | --- |
| 3D 화면 드래그 | 모형 회전 |
| 3D 화면에 초점을 둔 뒤 방향키 | 모형 회전 |
| `＋` / `−` 버튼 또는 해당 키 | 확대 / 축소 |
| 기본 시점 / 정면 시점 버튼 | 카메라 위치 변경 |
| 전체 화면 버튼 | 실험 관찰 영역 확대 |
| `움직임 멈춤` / `움직임 재생` | 애니메이션 일시 정지 / 재개 |
| 화면 품질 선택 | `가볍게 · 권장` / `선명하게` |

터치 화면에서는 두 손가락으로 확대·축소할 수 있습니다. 트랙패드의 일반 두 손가락 스크롤은 페이지를 이동하므로 확대·축소 버튼을 이용하면 편리합니다. 다른 탭을 보거나 관찰 영역을 벗어나면 렌더링이 쉬고, 돌아오면 이어집니다.

## 관찰 노트

`관찰 기록하기`를 누르면 실험 종류, 현재 조건과 결과, 기록 시각을 저장합니다. 기록의 입력란에 발견한 점을 최대 300자까지 적을 수 있습니다. 최대 기록 수는 40개입니다.

`기록 내려받기`는 `날씨연구소-관찰노트.csv`를 만듭니다. 열은 `실험`, `조건과 결과`, `내가 발견한 점`, `기록 시각`이며, 기록 시각은 UTC ISO 형식입니다. 한글을 위해 UTF-8 BOM을 포함합니다. CSV를 다시 가져오는 기능은 없습니다.

기록은 같은 사이트 주소의 같은 브라우저에 남습니다. 브라우저 데이터 삭제나 시크릿 모드 종료 등으로 사라질 수 있으므로 수업이 끝나기 전에 내려받아 보관합니다.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 파일을 더블 클릭했더니 화면이 작동하지 않음 | `npm start` 후 HTTP 주소로 접속했는지 확인 |
| 3D 화면을 열 수 없다는 안내 | WebGL 2 지원, 하드웨어 가속, 학교 관리 기기 정책 확인. 실험 조건·그래프·노트는 계속 이용 가능 |
| 화면이 느림 | 품질을 `가볍게 · 권장`으로 변경 |
| 처음부터 움직임이 멈춰 있음 | 운영체제의 동작 줄이기 설정에 따라 정지 상태로 시작할 수 있으므로 `움직임 재생` 선택 |
| 전체 화면이 열리지 않음 | 브라우저·학교 기기 정책·임베드 환경의 전체 화면 허용 여부 확인 |
| 기록이 저장되지 않음 | 브라우저 저장 공간 사용 가능 여부 확인 후 CSV로 내려받기 |
| `EADDRINUSE` 오류 | 이미 실행 중인 서버를 종료하거나 `PORT` 값을 변경 |

문제를 제보할 때는 브라우저·기기·실험 종류·조건·재현 순서를 함께 남겨 주세요.
