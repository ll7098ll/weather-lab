# 계산 모형과 가정

[README로 돌아가기](../README.md)

이 문서는 구현된 계산을 설명합니다. 계산은 주로 [`physics.mjs`](../dist/physics.mjs), 시각적 표현은 [`air-particles.mjs`](../dist/air-particles.mjs), [`motion.mjs`](../dist/motion.mjs), [`condensation-scene.mjs`](../dist/condensation-scene.mjs)에 있습니다.

## 이슬점과 응결

처음 공기 온도 `T = 24℃`, 상대 습도 `RH`에 대해 Magnus 형태의 근사를 사용합니다. `ln`은 자연로그입니다.

```text
γ = ln(RH / 100) + 17.625 × T / (243.04 + T)
Td = 243.04 × γ / (17.625 − γ)
```

`Td`는 ℃ 단위의 이슬점입니다. 구현 함수는 습도를 1~100%로 제한하며 UI의 조절 범위는 30~95%입니다. 이슬은 잎 표면, 안개는 지표 근처 공기의 온도가 처음 이슬점 이하가 될 때 생성 상태로 판단합니다. 처음 습도 설정은 처음 수증기 양을 정하며, 냉각 과정에서 현재 상대 습도를 고정한다는 뜻은 아닙니다.

## 상승한 공기와 구름

구름 시작 높이 `LCL`과 높이 `h`에서의 공기 온도는 다음과 같이 계산합니다. 높이는 m 단위입니다.

```text
LCL = 125 × (24 − Td)
T(h) = 24 − 0.0098 × min(h, LCL) − 0.006 × max(0, h − LCL)
```

응결 전에는 약 9.8℃/km, 이후에는 약 6℃/km로 냉각합니다. `h >= LCL`이면 구름이 생긴 상태로 판단합니다. 응결핵은 충분하다고 가정하며 물방울 구름만 표시합니다.

처음 습도 70%일 때 `Td ≈ 18.19℃`, `LCL ≈ 726.07m`이고, 2,500m에서 온도는 약 6.24℃입니다.

물방울의 표시량은 임계 조건을 넘은 정도를 0~1로 제한한 값이며 실제 응결 질량이 아닙니다. 9초 재생은 조건을 부드럽게 바꾸는 기능입니다. 실제 생성·증발 시간이나 질량 보존은 계산하지 않습니다.

## 기압 차와 흐름

두 지역의 기압을 `pL`, `pR`로 두고 다음 값을 사용합니다.

```text
Δp = pL − pR                         # hPa
흐름 방향 = sign(Δp)
상대 세기 s = clamp(|Δp| / 40, 0, 1)
```

양수는 지표 부근 왼쪽→오른쪽, 음수는 반대 방향이며 기압이 같으면 이 기압 차에 따른 전체 흐름은 없습니다. UI의 고기압·저기압은 두 지역을 비교한 결과입니다. 온도는 이 실험의 밀도·분자 운동 비교에 반영하며 전체 흐름의 방향은 설정한 기압 차로 정합니다.

순환 경로는 이동을 따라 보기 위한 닫힌 곡선입니다. 지구 자전·마찰·실제 풍속·대기 전체의 시간 변화는 계산하지 않습니다.

## 모래와 물의 비열

두 물질의 질량은 각각 `m = 1kg`입니다. 열 출입률 `P`는 J/초, 실험 시간 `t`는 0~300초입니다.

```text
Q = ±P × t
ΔT = Q / (m × c)
c(모래) = 830 J/(kg·℃)
c(물)   = 4,180 J/(kg·℃)
```

가열의 처음 온도는 20℃, 냉각은 30℃이며 두 실험은 독립적으로 시작합니다. 재생 중 실제 1초에 실험 시간 10초가 흐릅니다. 모래 비열은 고정된 대표값으로 취급하며 증발·혼합·주변과의 열 교환은 생략합니다.

온도 차의 절댓값이 0.05℃ 미만이면 전체 흐름을 표시하지 않고, 그 이상이면 따뜻한 쪽에서 상승하고 차가운 쪽에서 하강하는 개념 모형을 보여 줍니다. 상대 세기는 `clamp(|모래 온도 − 물 온도| / 20, 0, 1)`입니다.

## 공기 밀도와 입자 운동

건조한 공기의 밀도를 이상 기체 관계로 계산합니다.

```text
ρ = (p × 100) / (287.05 × (T + 273.15))
```

`p`는 hPa, `T`는 ℃이며 `ρ`는 kg/m³입니다. 기압 실험은 각 지역의 설정값을 사용합니다. 모래·물 실험은 바로 위 공기 온도를 표면 온도와 같다고 두고, 온도 효과를 비교하기 위해 양쪽 밀도 계산에 모두 1,010hPa를 사용합니다. 이 계산 가정이 실제 해륙풍에서 두 지역의 기압이 항상 같다는 뜻은 아닙니다.

기준은 24℃·1,010hPa, 기준 표시 점 수는 128개입니다. 기준 대비 밀도비를 `rρ`, 분자 운동의 대표 빠르기 비를 `rv`로 둡니다.

```text
rv = sqrt((T + 273.15) / (24 + 273.15))
강조 배수 g = 실제 비율 표시에서 1, 차이 강조에서 6
점 수 = clamp(round(128 × (1 + g × (rρ − 1))), 16, 256)
화면 운동률 = clamp(1 + g × (rv − 1), 0.25, 2.5)
```

밀도 숫자와 운동 배수 숫자는 원래 계산값을 보여 줍니다. 점은 많은 분자를 묶은 표시이며 실제 분자 수·크기·경로를 뜻하지 않습니다. 두 상자는 공기가 드나드는 같은 부피의 공간입니다. 온도가 같으면 기압이 달라도 대표 분자 운동 빠르기는 같고, 전체 바람이 없어도 분자 운동은 남습니다.

`입자 흐름` 화면은 192개의 표시 입자로 공기 덩어리의 이동을 나타냅니다. 이 점 수는 밀도나 바람 세기를 나타내지 않습니다. `밀도 비교`의 점 수와 구분해서 해석해야 합니다.

## 바람 세기와 움직임

화면의 바람 세기는 `round(100 × s)`이며 m/s 단위가 없는 상대 지표입니다. 목표 순환 속도는 `s = 0`이면 0, 그 외에는 `0.008 + 0.12 × s^1.25`회/초입니다. 세기·방향 변경 시 실제 표시 속도를 부드럽게 보간하고 이동 거리를 누적해 입자가 갑자기 다른 위치로 뛰지 않도록 합니다.

이 수치와 물방울 크기, 지형 높이, 색, 입자 운동은 수업에서 차이를 보기 위한 표현입니다. 일기 예보나 실측 자료로 사용하도록 설계되지 않았습니다.
